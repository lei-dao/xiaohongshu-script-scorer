# 小红书爆款口播稿评分器

一个用于评估、比较和优化小红书视频口播稿的 Codex Skill。

它用固定的 15 个维度分析稿件的文本传播潜力，既可以诊断单篇稿件，也可以比较多篇稿件或同一稿件的不同版本，并给出少而明确的修改建议。

> 这是内容诊断工具，不是平台审核工具，也不承诺实际流量。封面、标题、账号基础、拍摄表现、剪辑和发布时间等因素不计入稿件分数。

## 能做什么

- 单篇评分：查看稿件的优势、短板和最终得分。
- 多篇横评：使用同一量尺比较多篇稿件并给出排名。
- 版本对比：解释一次改稿提升了什么、牺牲了什么。
- 修改建议：默认只指出最值得改的 3 处，避免把内容改得过度标准化。
- 停止修改：当继续修改只会交换风格、损害自然度时，明确建议停止。

## 15 个评分维度

| 维度 | 主要判断 |
|---|---|
| 开篇冲击力 | 前几句能否让目标用户继续听 |
| 心理洞察深度 | 是否说出行为背后的深层心理机制 |
| 金句密度 | 可记忆表达的数量与分布是否合理 |
| 金句击穿力 | 最强表达能否击中认知或情绪 |
| 代入感 | 用户能否在场景和语言里认出自己 |
| 逻辑完整性 | 核心判断是否被连续、充分地推导 |
| 无廉价技巧 | 是否依靠内容成立，而非透支信任的套路 |
| 身份升级感 | 用户能否看见更主动、更清醒的自我身份 |
| 终局想象力 | 结尾能否呈现观点落地后的具体未来 |
| 可截图转发 | 是否存在脱离上下文仍有价值的内容单元 |
| 篇幅传播效率 | 每一段是否都在推动理解、情绪或行动 |
| 选题势能 | 选题是否天然值得明确人群关注和讨论 |
| 内容具体度 | 观点是否有细节、案例、步骤或推理支撑 |
| 中段推进力 | 开头之后是否持续产生新信息和期待 |
| 口播自然度与节奏 | 文本是否像自然说话，便于停顿、强调和剪辑 |

每个维度按 1–10 分评分，允许使用 0.5 分。15 项完全等权：

```text
最终得分 = 15 项分数之和 ÷ 15
```

最终只展示 10 分制得分，并保留一位小数。多篇稿件分差不超过 0.2 分时，不判断为明显胜负。

## 得分参考

| 最终得分 | 含义 |
|---:|---|
| 9.0–10 | 极强文本表现，高分必须有充分原文证据 |
| 8.0–8.9 | 明显强稿，只需处理少数关键短板 |
| 7.0–7.9 | 具备传播基础，仍有清晰提升空间 |
| 6.0–6.9 | 基本成立，但竞争优势不足 |
| 低于 6.0 | 存在结构性短板，应先修核心判断或主线 |

这些等级描述的是稿件本身，不对应播放量、点赞量或爆款概率。

## 使用方式

将仓库克隆到 Codex 的 Skills 目录：

```bash
git clone https://github.com/lei-dao/xiaohongshu-script-scorer.git ~/.codex/skills/xiaohongshu-script-scorer
```

然后通过 `$xiaohongshu-script-scorer` 调用。

### 单篇评分

```text
使用 $xiaohongshu-script-scorer 给这篇小红书视频口播稿评分，指出最值得修改的三处：

[粘贴口播稿]
```

### 多篇比较

```text
使用 $xiaohongshu-script-scorer 比较下面三篇口播稿。请使用同一量尺评分，告诉我哪篇更强，以及每篇的胜负手：

稿件 A：……
稿件 B：……
稿件 C：……
```

### 比较改稿前后

```text
使用 $xiaohongshu-script-scorer 比较原稿和修改稿。说明哪些改动值得保留，哪些改动损害了自然度：

原稿：……
修改稿：……
```

## 输出原则

- 每项分数都必须有原文证据，不能只凭整体印象。
- 相邻维度使用不同判断边界，避免同一问题被重复扣分。
- 默认只给 3 个最高优先级建议，并说明修改可能带来的副作用。
- 保留作者原意、口吻和事实边界，不虚构经历、案例、数据或结果。
- 不把高分解释成“必爆”，也不把低分解释成“必定没有流量”。
